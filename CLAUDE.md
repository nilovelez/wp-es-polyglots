# WordPress translation workbench: es_ES

Working repository of Nilo Vélez (es_ES PTE in Polyglots) to translate and review WordPress strings into Spanish (Spain) with AI help. Answer in the language Nilo writes in; be short and exact (if he asks for a field or a command, give only that).

Read first: [README.md](README.md) (subprojects and layout), [docs/status.md](docs/status.md) (current milestone, open questions) and [docs/workflow.md](docs/workflow.md) (how we work).

## Languages

- English: file and folder names, code, comments, project docs (`README.md`, `docs/`, subproject READMEs), commit messages. This repo must be clonable by other locale teams.
- Spanish: everything specific to the locale (`resources/`, round notes, calibration log, translations).

## Before translating or reviewing

Read `resources/quick-reference.md`, `resources/style-guide.md` and `resources/glossary.csv` (its notes, such as "No usar…", are mandatory). Priority on conflict: Nilo's instructions → glossary → style guide.

## Rules

- Review rounds follow [review/README.md](review/README.md).
- `polyglots/rules/es_ES.yaml` is generated by `python3 polyglots/rules/build_rules.py`; never edit it by hand. Run the tests in [polyglots/README.md](polyglots/README.md) after every change.
- One occurrence of a mistake is a candidate; it becomes a rule when it repeats or when the guide or glossary state it. Rules must be generic, never specific to one plugin.
- `polyglots` never uploads or approves anything; Nilo does.
- Keep `docs/status.md` up to date when a milestone or an open question changes.

- **Marcianito** (Windows 11, RTX 2060 12 GB): `polyglots` (working folder `Z:\polyglots`) and Ollama. `polyglots rules check` and the rounds run there.
