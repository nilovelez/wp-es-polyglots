# Términos y decisiones de la ronda 20 (TWT AEO Ultimate)

Registro de cada elección de término, para mantener la coherencia entre tramos.
Se actualiza al final de cada tramo.

## Mayúsculas (decidido en el tramo 1, aplicado en 2)

- Nombres de funciones, módulos, vistas, pantallas y páginas del plugin en mitad de frase en prosa: minúscula
  (visibilidad en IA, motor RAG, citas de IA, posicionamiento en búsquedas, vista de fragmentos,
  registro de rastreadores, vista de bot, motor de carencias de contenido, rescate de 404 inteligente,
  mapa del sitio como módulo, grafo social como pantalla, tienda local como módulo).
- Se mantienen las mayúsculas en: etiquetas de botón o enlace («Ir a Visibilidad en IA», «Abrir Visibilidad en IA»,
  «Guardar», «Editar», «Copiar», «Iniciar», «Deshacer», «Volver a analizar»), rutas de menú con flecha
  («AEO Ultimate → Visibilidad en IA», «Escritorio → Actualizaciones»), menús y ajustes de WordPress o del plugin
  citados como lugar («Ajustes», «Módulos», «Herramientas»), pestañas y campos («Reglas de precios», «Servicio», «Credenciales»),
  nombres entre «» y títulos al inicio de frase.
- «Escritorio» (Dashboard de WordPress) en mitad de frase en prosa: minúscula («del escritorio»).
- Nombres de categorías y frases de ejemplo en mitad de frase: minúscula («kits de iniciación», «menos de 500 $»).

## Glosario (aplicado)

- set (verbo) → «establecer» («set to», «set by», «set as»; «establecido», «establecida»). «set up» / «set it on» → «configurar» / «configúralo» / «establécelo» (ver nota de conflicto).
- check (verbo) → «comprobar» (no «revisar», no «comparar»). check (sustantivo) → «comprobación».
- next (adjetivo) → «siguiente» («tu siguiente ejecución», «Siguiente barrido»); «ask next» → «preguntar después».
- hover → «al pasar el cursor».
- how-to → «guía práctica».
- caption (imagen) → «leyenda». «blockquote» no se traduce (etiqueta HTML).
- FAQ → «FAQ» (no se traduce; no «preguntas frecuentes»).
- fix (sustantivo) → «corrección» (no «solución»). fix (verbo) → «corregir».
- delete (documentos, tablas, colecciones) → «borrar» / «Bórralo». remove → «quitar» / «eliminar» (físico).
- upload → «subir» / «subida»; uploaded → «subido».
- save → «guardar».
- writable → «tener permisos de escritura»; «is not writable» → «no tiene permisos de escritura».
- checkout (página de pago) → «finalizar compra».
- monitor / tracked → «supervisar» / «supervisadas»; «desde que se empezó a seguir» en «since first tracked».
- sets the ceiling → «establece el máximo».
- host (empresa) → «proveedor de alojamiento». «host panel» → «panel del servidor».
- dashboard de un servicio de terceros («agency dashboard») → «panel»; Dashboard de WordPress → «Escritorio».
- report (verbo) → «informar». report (sustantivo) → «informe».
- role → «perfil» (no «rol»). membership → «membresía». membership tier → «nivel de membresía».
- landing page → «página de destino» (no «página de aterrizaje»).
- stock → «existencias» («sin existencias»).
- variation → «variación».
- scope (UI, selector de ámbito) → «ámbito». (La entrada del glosario «extensión» es para el atributo scope de las celdas de tabla.)
- render → «procesar» en contexto de programación («se procesa en el navegador», «debe procesarse en el servidor»); «mostrar» cuando son elementos en la página. «generar» se usa en casos de contenido generado por IA (ver conflicto).
- library → «biblioteca» (no «librería»). lazy → «diferida» («carga diferida»).
- email → «correo electrónico» en textos largos.
- meta description → «meta descripción» (overrides); meta descriptions → «meta descripciones».
- merchant (genérico) → «vendedor»; merchant en nombres de producto (Merchant Center, Merchant API) → se mantiene en inglés.
- endpoint → se mantiene «endpoint» (ver conflicto).

## Conflictos o dudas de glosario (para la respuesta final)

- toggle: el glosario da «conmutador» (sustantivo) y «cambiar / alternar» (verbo); en las etiquetas «Toggle X» se mantiene «Activar o desactivar X» porque el glosario queda raro en la interfaz.
- authenticate: el glosario da «identificar»; «autenticar» evitado por la norma del equipo.
- prompt: aplicado «instrucción».

- render: el glosario dice «procesar» en programación; en el tramo 2 se ha aplicado «procesar» en los casos de render en servidor/navegador, pero «se muestra por completo con JavaScript» se mantiene como «mostrar».
- endpoint: el glosario da «variable», que no encaja con «endpoint de la API» (en el tramo 2 se mantiene «endpoint»).
- OK (564 y similares): el glosario da «Aceptar»; se usa «Correcto» en etiquetas de estado.
- set: en el glosario «establecer»; «configurar» se mantiene cuando es «set up» (configuración de herramientas).
- Merchant: el glosario da «vendedor» para el término genérico; en nombres de producto se mantiene el inglés.
- scope: el glosario lo da como «extensión» (celdas de tabla); en este plugin es el selector de ámbito.

## Revisión final (tras el tramo 5)

- «Ajustes», «Módulos», «Herramientas» y «Escritorio» en rutas, pestañas y menús: se mantienen con mayúscula.
- «check» verbo: «comprobar» (o «compruébalo»). Revisado en todo el archivo.
- «next» → «siguiente»: corregidas las apariciones con «próxim-» (2014, 2761, 2771, 3078, 3618). Revisado.
- «set» → «establecer» cuando es estado («establecida como privada»); «configurar» cuando es «set up» o ajuste de opciones. Revisado.

- Rol de usuario de GA4 («role: Viewer» → «rol: Lector»): se mantiene «rol» porque es la etiqueta de la interfaz de GA4; el glosario dice «perfil» (ver conflictos).
- «merchant»: las 45 apariciones son nombres de producto (Merchant Center, Merchant API, Merchant ID); no se aplica «vendedor».
