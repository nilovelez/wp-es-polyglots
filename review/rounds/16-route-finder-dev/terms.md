# Decisiones de términos (ronda 16, route finder dev)

Se aplican en todo el archivo. Se revisan antes de cada tramo.

## Del glosario

- **zoom** (sustantivo y verbo) → **ampliación** (nombre), **ampliar** (verbo), **acercar** / **alejar** (zoom in / zoom out). No se deja en inglés. «Botones de acercar/alejar» se mantiene.
- **default** → **por defecto**, no «predeterminado».
- **hero** (sección, página, tarjeta) → **destacada/destacado**: «Sección destacada», «página destacada», «tarjeta de mapa destacada».
- **hover** → **al pasar el cursor**.
- **tooltip** → **información emergente**.
- **modal** → **emergente** («ventana emergente»).
- **frontend** → **parte pública**.
- **slider** (widget o filtro) → **control deslizante**; «tirador» para el pulgar.
- **scroll** (sustantivo) → **desplazamiento** («desplazamiento infinito»). Para la rueda del ratón, «rueda».
- **delete** → **borrar**, en botones, avisos y mensajes.
- **remove** → **quitar**. «Eliminar» solo para borrados físicos.
- **deselect** → **anular selección**.
- **are you sure** → **¿Seguro que…?**
- **library** → **biblioteca**.
- **login** / **log in** → **acceder** / **acceso**. No «inicio de sesión».
- **setting** → **ajuste**; **settings** → **ajustes**. No «configuración» para estos dos.
- **curated** → **seleccionado** («paradas seleccionadas»).
- **header** (cabecera de tabla o sección) → **cabecera**.
- **collapsed** → **plegado**; **collapse** → **plegar**.
- **unable** → **no se ha podido**.
- **customize** → **personalizar**.
- **link** (verbo) → **enlazar**; (sustantivo) → **enlace**.

## Del proyecto (decisiones propias de la ronda)

- **climb** → **subida**; **climbing** → **escalada** («Perfiles de escalada», «Estadísticas de subida»).
- **ascent** → **desnivel** en las etiquetas de datos (Desnivel mín., Desnivel máx.). Se revisa la aparición de «ascenso» en el resto del archivo.
- **tile** → **mosaico** (no «teselas»).
- **POI** → **PDI** (se mantiene la sigla).
- **tea stop** / **stop** → **parada**.
- **destination** → **destino**; **mid-route** → **a mitad de ruta**.
- **marker** → **marcador**; **custom marker** → **marcador personalizado**.
- **route** → **ruta**; **route info page** → **página de información de la ruta**.
- **group** → **grupo**; **club group** → **grupo del club**.
- **mini map** → **minimapa**; **large map** → **mapa grande** / **mapas grandes**.
- **fitbounds** → **ajuste a los límites** («Ajustar a los límites»).
- **colour** → **color**; **pixel** → **píxel**.
- **gradient** → **gradiente**; **solid** → **sólido**.
- **Ver** (menú del mapa) se mantiene como nombre de menú.
- **Google Street View**, **Strava**, **Leaflet**, **OpenStreetMap**, **Google Places** y los proveedores de mapas no se traducen.
- **Routes → Custom Markers** (menú de WordPress) se traduce como «Rutas → Marcadores personalizados».

## Forma de tratamiento

- Tuteo en todo el texto: «configura» (no «configure»), «considera», «desmárcalo», «vuelve».

## Tipografía

- Comillas «» en todo el texto. Las comillas rectas del original se cambian.
- Títulos y etiquetas en mayúscula solo en la primera palabra. Se corrigen los títulos en «Title Case» salvo nombres propios.

## Añadidos en el segundo tramo (821–1635)

- **bulk** → **por lotes** («Editar rutas por lotes», «Acción por lotes no válida»).
- **toggle** (sustantivo) → **conmutador**; **toggle** (verbo) → **alternar**.
- **preset** → **preajuste**.
- **shortcut** (acceso rápido a rutas) → **atajo**.
- **role** → **perfil** («perfiles de usuario»).
- **elevation** → **elevación** en todo el plugin (incluidas etiquetas y «Sin datos de elevación»); **ascent** → **desnivel**.
- **sign in** → **acceder**; **login** / **logged in** → **acceder** / **conectado**; **sign out** → **salir**.
- **required** → **obligatorio** («Contraseña obligatoria»).
- **embed** (verbo y sustantivo) → **incrustar** / **incrustación**.
- **mini map** → **minimapa**.
- **Clear** en botones → se mantiene «Borrar» o «Limpiar», según el peer; no se cambia a «vaciar».
- Entidades HTML (`&amp;`, `&rarr;`, `&mdash;`) se mantienen intactas.
